# Kalkulator całek

Program do liczenia całek oznaczonych

## Instrukcja

Wymagane jest zainstalowane `Node.js`, `npm` oraz `git`. Dodatkowo, trzeba posiadać konto w Firebase.

### Sklonuj repozytorium:

```git clone https://github.com/DzaneQ/KalkulatorCalek.git```
```cd KalkulatorCalek```

### Uzupełnij konfigurację Firebase:

Utwórz konfigurację Firebase i wykonaj plik według wzoru w pliku `src/firebaseInit.js.sample` zapisując jako `src/firebaseInit.js`.


### Zainstaluj paczki i uruchom aplikację:

```npm install```
```npm run serve```
